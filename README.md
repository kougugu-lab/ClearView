# ClearView 静止画撮影システム

**バージョン**: 1.3.3

---

## 複数カメラ対応

- 最大4台のUSBカメラを登録できます。設定画面の「カメラ」タブで対象カメラを選び、追加・削除・表示名・カメラ番号を設定します。
- 解像度、プレビュー解像度、オートフォーカス、露出などのカメラプロパティは、カメラごとに保存されます。
- 1回のトリガーで全登録カメラを同じ撮影回数だけ撮影し、プレビューは最大2列のグリッドで表示します。
- 保存名は `{コミット番号}_{カメラ名}_{連番}.jpg` です。例: `0001_カメラ1_01.jpg`。
- 旧バージョンの単一カメラ設定（`camera`）は、初回起動時に `cameras` 配列の1台目へ自動移行されます。

---

## このプログラムについて

このプログラムは、**カメラを使って指定した枚数の静止画を高解像度で自動撮影・保存するシステム**です。
AI判定・OCR・QRコードの読み取りなどは行わず、**撮影と保存だけに特化したシンプルなカメラシステム**です。

---

## 主な機能

1. **トリガー連動撮影**
   - 外部センサーやPLCからのトリガー信号（GPIO）をきっかけに撮影を開始します。
   - 設定した「撮影回数」分だけ、設定した「撮影間隔」をあけて連続撮影します。

2. **高解像度保存（カスタム入力対応）**
   - 本撮影は設定した静止画解像度で保存します。
   - 3840x2880 など、任意の解像度をコンボボックスへ手入力（カスタム指定）できます。
   - プレビュー表示用と本撮影用の解像度を個別に設定できます。

3. **コミット番号管理**
   - 1トリガー（1サイクル）完了ごとにコミット番号を自動インクリメントします（0001〜9999）。撮影失敗時も進みます。
   - テンキーダイアログから任意の番号に手動設定も可能です。

4. **GPIO 出力**
   - 撮影成功時: OK 出力ピンにパルス信号を出力します。
   - 撮影失敗時: NG 出力ピンにパルス信号を出力します。
   - システム起動中: 「システム起動中」ピンをON状態に保ちます。

5. **容量監視・自動削除（inspection_app 準拠）**
   - 指定した容量上限（GB）を超えた場合、またはディスク空き容量が 1.0 GB 未満になった場合、古い結果画像から順に自動削除します。

6. **設定画面**
   - タブ形式の設定ダイアログから、すべての設定を GUI で変更できます。
   - 設定は `config.json`（プログラムと同一フォルダ）に保存されます。

## 動作フロー

```
起動
  │
  ├─ 設定ファイル読み込み (config.json)
  ├─ 結果フォルダの自動生成 (結果保存フォルダのみ)
  ├─ カメラ初期化
  └─ GPIO（トリガー・出力）の初期化
          │
          ▼
  [トリガー待機ループ]
  トリガー信号の受信 (GPIO / テンキー番号入力ダイアログ起動)
          │
          ▼
  カメラ解像度を「本撮影の解像度」に切替 → バッファクリア
          │
          ▼
  「撮影回数」枚を「撮影間隔」おきに連続撮影
  ├─ 成功: OK 出力
  └─ 失敗: NG 出力
          │
          ▼
  コミット番号+1（成功・失敗にかかわらず1サイクル完了で進行）
          │
          ▼
  カメラ解像度を「プレビュー解像度」に戻す
          │
          ▼
  [トリガー待機に戻る]
```

## ファイル構成

```
ClearView/
├── main.py               ← エントリーポイント
├── config.json           ← 設定ファイル（GUI から自動更新）
├── modules/
│   ├── __init__.py
│   ├── app.py            ← メインアプリケーションクラス
│   ├── constants.py      ← 定数定義（テーマカラー・フォント・解像度リスト）
│   ├── dialogs.py        ← 設定ダイアログ（SettingsDialog）
│   ├── settings.py       ← 設定ファイル読み書き（SettingsManager）
│   └── widgets.py        ← 共通UIウィジェット（TenKeyDialog等）
├── logs/                 ← アプリケーションログ（自動生成）
└── results/              ← 撮影された高解像度静止画（results_dir 指定パス）
```

## 設定項目一覧

### カメラ設定
| 項目 | デフォルト | 説明 |
|------|-----------|------|
| 撮影カメラインデックス | 0 | USBカメラのデバイス番号 |
| カメラプロパティ (フォーカス/ゲイン/露出等) | -1 (デフォルト) | 手動値。`-1` はカメラデフォルト（プレビュー中に値を変更すると即時反映） |
| 調整エリア自動調整 | — | 設定タブ右パネルのプレビュー上で調整エリアを1回指定すると、全プロパティの「自動調整」で共通利用 |

### 解像度設定
| 項目 | デフォルト | 説明 |
|------|-----------|------|
| 本撮影の解像度 | 1920x1080 | 保存する静止画の解像度 (手入力可能) |
| プレビュー解像度 | 640x480 | リアルタイムプレビュー表示解像度 |

### GPIO ピン設定
| 項目 | デフォルト | 説明 |
|------|-----------|------|
| トリガー入力ピン | 22 | 撮影開始トリガーのBCMピン番号（内部プルアップ常時有効） |
| システム起動中ピン | 5 | アプリ起動中にONにするピン |
| OK 出力ピン | 16 | 撮影成功時の出力ピン |
| NG 出力ピン | 20 | 撮影失敗時の出力ピン |
| OK 出力時間 (秒) | 0.5 | OK パルスの継続時間 |
| NG 出力時間 (秒) | 0.5 | NG パルスの継続時間 |
| トリガー入力信号状態LED | — | 物理ピンの入力信号状態をリアルタイム点灯/消灯表示するランプ |

### システム設定
| 項目 | デフォルト | 説明 |
|------|-----------|------|
| 撮影回数 | 5 | 1トリガーあたりの撮影枚数 |
| 撮影間隔 (秒) | 0.2 | 連続撮影のコマ間隔（0で間隔なし） |
| 結果表示時間 (秒) | 2.0 | 撮影後に結果を表示する時間 |
| プレビュー更新レート | 15 | リアルタイムプレビューの表示更新 FPS (1〜60) |
| 古い結果画像を自動削除する | True | 容量上限時の自動削除の有効化 |
| 最大容量上限 (GB) | 10.0 | 自動削除を開始する画像フォルダの最大サイズ |
| コミット番号を 0.5 刻みで進める | False | 有効にすると撮影完了ごとに +0.5（ドアライン対応） |

### 保存フォルダパス設定
| 項目 | デフォルト | 説明 |
|------|-----------|------|
| ログフォルダ | ./logs | ログファイル出力先フォルダ |
| 結果保存フォルダ | ./results | 撮影画像が保存されるフォルダ |
